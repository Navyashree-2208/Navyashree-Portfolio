# Navyashree Portfolio — React + Node.js

This project recreates the supplied single-file portfolio without changing its visual design, text, sections, colors, animations, navigation, project modals, or form behavior.

## Stack
- HTML — Vite entry document
- CSS — original CSS preserved in `src/styles.css`
- JavaScript — React behavior/components
- React — frontend UI
- Node.js + Express — backend/server structure

## Run
```bash
npm install
npm run dev
```

Frontend: http://localhost:5173
Backend: http://localhost:5000

For production:
```bash
npm run build
npm start
```
